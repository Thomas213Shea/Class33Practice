github commands.

1. git init
2. git remote add origin https://github.com/Thomas213Shea/git.git
3. git add .
4. git commit -m "message"
5. git push -u origin main

Updating commands:
1. git add .
2. git commit -m "message"
3. git push 

Branch commands:
1. git checkout main
2. git pull origin main
3. git checkout -b branchname
4. git add .
5. git commit -m "message"
6. git push origin branchname
